## Статус

Код готов: серверная миграция (S1–S4) завершена, настройки поля не требуют ручного ввода ID,
REST-факты сверены с живым порталом (`pnpm b24:smoke`). **Не сделано главное — живой прогон на
портале**: установка, работа поля в карточке и приход события удаления кодом не проверяемы.
Порядок работ — [`MANUAL_TEST_PLAN.md`](MANUAL_TEST_PLAN.md) → [`MARKETPLACE_RELEASE.md`](MARKETPLACE_RELEASE.md).
Актуальный срез — [`PROJECT_MAP.md`](PROJECT_MAP.md) и [`SERVER_MIGRATION.md`](SERVER_MIGRATION.md).
